Direction 2 — Switchboard

Seat: Steel (Viktor Stahl) · Movement: Brutalist / Systems-first · Default mode: dark · Type: Chivo + Chivo Mono

A day is a dispatch board. Every slab on it is a fact: when it starts, how long it runs, whether it is done, and — the thing every other planner hides — how much of the day is genuinely free, drawn as an honest dashed slot you can drop into. The status strip across the top is the only summary you get, and it never lies: planned, free, done, late, unplaced. Graphite greys carry the whole interface; the single cobalt signal is spent on exactly three things — the now line, the running block, and whatever you are holding. Category colours are deliberately desaturated so they read as labels, never as alarms (a stated departure from the seat's greys-only rule, because the brief requires colour-coded categories). Chivo Mono is confined to the time gutter, durations and counters, where fixed-width alignment is load-bearing. Motion is 90 ms linear or none: a dragged slab follows your finger at 1:1, snaps on release, and nothing eases in for effect. The quick-add is a command line because the later AI layer is a command line with more words.

Flow review (Ingrid Falk) — within the aesthetic

  • 🟢 Create: command line is always one keystroke away (/) and pinned on mobile; the parse row shows every field before Enter, and Tab walks the fields to fix a bad parse. No parse ambiguity is ever silently resolved.
  • 🟢 Drag-to-reschedule: grabbed slab is unmistakable (2 px cobalt, hard shadow); dashed ghost snaps to 5 min with the time in the gutter; drop onto a free row or an occupied one (occupied prompts: swap, or push later).
  • 🟡 Resize: the 8 px handle strip is fine with a mouse but under 44 px for touch. Addressed: on mobile the handle only appears on a selected slab, and its hit area extends 22 px above and below the strip; live duration tag during the gesture.
  • 🟢 Complete: square checkbox at 44 px hit, X on keyboard; done slabs lose their fill and stripe so the board reads at a glance. Undo toast, 5 s.
  • 🟡 Mobile inbox → timeline: the Backlog is a separate tab, so cross-tab drag is not viable. Addressed: Place opens a slot picker generated from the day's actual free rows (earliest first), plus pick-a-time. Open trade-off: no long-press drag from Backlog to Board in v1; Board's free rows have a + target instead.
  • 🟡 Density: 11 px mono labels are acceptable as non-interactive tick labels only; all interactive text is ≥ 12.5 px. 15-minute tasks render as a single 22 px line, expandable on tap. Flagged for a real-device legibility check.
  • 🟢 Accessibility: contrast ink-2 on bg is 6.9:1 (dark) and 7.1:1 (light); category is stripe + name, never colour alone; full keyboard map under ?; no motion to reduce.
