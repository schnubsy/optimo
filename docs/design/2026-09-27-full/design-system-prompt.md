## 2. Visual rules (exact)

- **Type.** Display = `var(--font-display)` italic 400, used ONLY for: day title (32px desktop / 24px mobile), hour numerals (20px desktop / 16px mobile, right-aligned, tabular), free-time label (14px), sheet title (24px), focus timer (40px, upright). Everything else = `var(--font-ui)`: block title 15px/700 (14px in blocks < 40px tall), block time 12px/500 tabular, inbox title 15px/700, meta 13px/400, chips/tabs 13px/700, body 15px/400, micro 11px/700. No text below 11px. No ALL-CAPS labels. No monospace anywhere.
- **Canvas & surfaces.** `--canvas` page; `--panel` for the inbox rail, tab bar, sheet; `--surface` for inputs, quick-add, inbox rows, done blocks. Borders use `--line`; never hairline decorative rules.
- **Timeline block** (`Block.tsx`): `article` with `style={{'--cat-h': category.hue}}`; CSS `background: oklch(var(--tint-l) var(--tint-c) var(--cat-h)); color: oklch(var(--tint-ink-l) var(--tint-ink-c) var(--cat-h)); border-radius: var(--r-md);` and `border-radius: var(--r-pill)` when height < 40px. Padding `var(--block-pad-y) var(--block-pad-x)`. Icon chip: 28px circle, absolutely positioned top 8px right 8px, `background: oklch(var(--chip-l) var(--chip-c) var(--cat-h))`, glyph 16px white — except hue 170 and 95 where the glyph is `oklch(0.20 0.02 var(--cat-h))`; hide the chip below 40px height and show an 18px inline chip before the title instead. Priority: 3px inner-left bar (`--prio-high|med|low`), hidden for none. Checkbox: 18px circle, 1.5px `currentColor`. Height = `duration_min * var(--px-per-min) - var(--block-gap)`; blocks under 30px get a `::before` hit-area extending to 44px.
  - States: `:hover` → `--tint-hover-*`; `[data-selected]` → `outline: 2px solid currentColor; outline-offset: -2px`; `[data-running]` → same outline + a "now" chip in `--accent-tint`/`--accent-ink` after the title; `[data-done]` → `background: var(--done-tint); color: var(--done-ink)`, title `text-decoration: line-through`, chip shows the check glyph on `--done-ink`; `[data-dragging]` → `transform: scale(var(--scale-lift)) translateY(var(--lift-y)); box-shadow: var(--shadow-drag)` plus `--tint-drag-*`; dark theme adds `box-shadow: inset 0 0 0 1px oklch(1 0 0 / .06)`.
  - **Resize handle**: render a 44px-tall invisible band at the block's bottom edge (`position:absolute; left:0; right:0; bottom:-22px; height:44px; cursor: ns-resize; touch-action: none`) containing a visible 28×5px pill (`currentColor` at 40% alpha) shown on hover/selected. Pointer-drag on the band changes the block's visual height live (transform-free: set `height` on the preview layer only) and on release calls the existing repo update with **`duration_min` only** — `start_at` must not change. Snap to the settings value (5/10/15). Add a vitest case in `tests/unit/layout.test.ts` asserting the resize commit payload contains `duration_min` and not `start_at`, and a Playwright step in `tests/timeline.spec.ts` that resizes, reloads, and asserts the persisted height — this is the fix for the duration-not-persisting bug.
- **Free-time connector** (`FreeRow.tsx` → rename `FreeGap.tsx`): for each gap ≥ 10 min, a `button` spanning the gap; content: a centred vertical `border-left: 2px dotted var(--free-line)` from top+6px to bottom−6px; an italic display label "1 h 15 free" (14px, `--free-label`) on a `--canvas` pill at the vertical midpoint; a 24px "+" circle (`--surface` bg, `--ink`) at the right edge. Below 30 min show only the "+". `aria-label="1 hour 15 free from 07:45, add task"`. Click → create at gap start, duration `min(gap, default)`. During drag it is a dnd-kit droppable: pill bg `--accent-tint`, dots `--accent`. Hover: pill bg `--free-hover`. **Remove the dashed drop-row styling entirely.**
- **Now line** (`NowLine.tsx`): `height: 0; border-top: var(--now-line-w) solid var(--now-line)` from the gutter's left edge across the column; flag pill in the gutter (`--now-flag-bg`/`--now-flag-fg`, 11px 700 tabular); `aria-hidden`; position via `transform: translateY()` with a 250ms `--ease-standard` transition; update every 30 s.
- **Hour rail** (`HourRail.tsx`): gutter width `--gutter-w` (`--gutter-w-mobile` under 900px); numerals in `.display` 20px/16px, `--ink-2`, right-aligned, 8px from the column; hour lines `1px solid var(--line-strong)`, half-hour lines `1px solid var(--line)`.
- **Inbox** (`Inbox.tsx`): rows `--surface` bg, `--r-md` 14px, 6px gap, min 56px; 18px chip + title 700 + meta "Personal, 0:30" (no middle dots) + Place pill (`--accent`, `--ink-on-accent`, 32px, 44px hit area). Empty state: display italic "Nothing waiting." Mobile: the inbox is a full-height tab, not a sheet; tab badge shows the count.
- **Quick-add** (`QuickAdd.tsx`): 44px pill (`--surface`, `--r-pill`), leading "+" in `--accent`, placeholder "Add a task — try 'Lunch with Sam at 1pm for 1h #personal'"; parse-preview row of 44px chip buttons (`--surface`, category chip in its tint/ink). Keep `parse.ts` untouched.
- **Editor** (`TaskSheet.tsx`): mobile bottom sheet `--r-sheet` top corners, `--panel`, `--shadow-sheet`, 36×5 grabber `--n-300`; desktop 420px side panel `--r-lg`. Title in `.display` 24px, editable. Category picker = 8 chips (40px circles, chip colour, glyph, selected = `outline: 2px solid var(--ink); outline-offset: 2px`). Duration = pill chips 30/45/60/90/2h + custom. Inputs `--surface`, `--r-sm`, 44px. Save = primary pill 48px full width; Delete = text `--danger`. Keep the "Adjust to actual" banner, styled `--accent-tint`/`--accent-ink`.
- **Week** (`Week.tsx`): compact blocks `--r-sm`, tint/ink, 11px/700, chip hidden below 36px; today column bg `color-mix(in oklch, var(--accent-tint) 40%, transparent)`; free gaps ≥ 45 min as dotted rules with "1:15" in 10px `--ink-2`; day header "Sat 26" 700 + "6h30 · 3h20 free" 11px `--ink-2`.
- **Tab bar / FAB**: tab bar `--panel`, `border-top: 1px solid var(--line)`, 4 items, 24px icons outline (filled when active), 11px/700 labels, active `--accent`, inbox badge pill. FAB 56px `--r-pill` `--accent` white "+", `--shadow-fab`, `right: 16px; bottom: calc(64px + env(safe-area-inset-bottom) + 16px)`; press `scale(var(--scale-press))`. No FAB on desktop.
- **Buttons/inputs/chips**: primary `--accent`/`--ink-on-accent`, 44px, `--r-pill`, 15px/700, hover `--accent-hover`, active `--accent-active`; secondary `--surface`; disabled `--n-300` bg / `--n-500` text; inputs `--surface` `--r-sm` 44px, error `2px solid var(--danger)` + `--danger-ink` message; chips 32px pills.
- **Icons**: keep the in-repo 24px set in `src/icons/`; add a `filled` prop per glyph (solid silhouette with one 2px counter-cut). 16px inside 28px chips, 20px in chrome. Never import an icon library.
- **Motion**: use the token durations/easings only. Hover/press 100ms; check draw 150ms then tone 200ms; block appear 200ms `--ease-emph-decel` (`translateY(8px)→0`, opacity, `scale(.97)→1`); reflow 250ms `--ease-standard` on `transform`; drag settle 480ms `--ease-settle`; sheet open 380ms `--ease-drawer`, close 250ms `--ease-accel`, scrim 200ms. Drag remains transform-only (dnd-kit). Completion burst: 6 dots in the chip colour, 400ms, only on user tap. Under `prefers-reduced-motion` the tokens zero the transforms — do not add component-level exceptions.
- **Dark mode** is entirely token-driven; do not hard-code colours in components. Every block gets the 1px inset ring in dark (already in the CSS above).
