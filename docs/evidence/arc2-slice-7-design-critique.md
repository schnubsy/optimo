# Arc 2 · slice 7: Eye design critique (LITE)

**Scope.** This reviews the arc-2 implementation evidence (slices 2–6) against the ratified FINAL design (`docs/design/2026-09-27-final/final.html`, `spec.md`, `tokens.css`). It is a critique only. No new directions are proposed, and no ratified decision is re-opened.
**Accepted as intended (not findings):** `tokens-a11y.css` override layer (done-ink 0.51/0.66; ink-3 not used for text), mobile header solid under its text, week "plan · free" label (snag #4), light as base theme.
**Severity:** 🔴 P0 = must fix this slice · 🟡 P1 = GitHub issue labelled `snag` · 🟢 = fine / praise. Size S = under half a day, M = around a day.

**Verdict.** The pill system, the chip-as-control rule, the free-time connector and the floating chrome geometry all land faithfully in both themes. The P0s are about layout under pressure: header overflow at 1280px, overlap-pill truncation, bar legibility and the keyboard-covered quick-add row. None of them is about the visual language.

## 🟢 Fine / praise

- **A2-G-1 Pill system faithful in both themes.** Pastel fills with same-hue ink titles and dusty L 0.55 chips with white glyphs in light. In dark, pills at L 0.40 with bright chips and dark glyphs, plus the inset ring. Hues map correctly to categories.
- **A2-G-2 Chip is the complete control.** No checkbox anywhere. The done state (neutral fill, strike, check glyph) reads clearly even in compact week pills. The priority ring on the chip is clear (P1 coral ring on "Write the migration plan").
- **A2-G-3 Free-time connector matches spec §5.3:** centred dotted rule, sage "1h 30m free" label pill, "+" circle at the right, in both themes.
- **A2-G-4 Floating chrome geometry is exact.** Bar left 16 / right 88 / 60px tall, FAB 56px, four tabs with the hidden Plan slot. The badge, the filled active tab and the outlined inactive tabs are correct. The mobile header (title in 800 with the date part in accent, stats, 7-day strip with a 24px accent circle) is on spec.
- **A2-G-5 Desktop segmented control placed top-left** of the pane per §4, with the quick-add pill and gear on the same row.
- **A2-G-6 Microcopy on voice:** "Nothing waiting — enjoy the space.", "iCloud calendar connected.", the Reminders copy (honest, no exclamation). The empty state uses the §10 pattern (40px chip plus one line).
- **A2-G-7 iCloud events are unmistakably read-only:** outlined pills with no fill, "iCloud · read-only" in the details. They share overlap columns and change the free totals.
- **A2-G-8 Glyph set is coherent and original:** consistent filled weight and round corners, drawn in-repo. Auto-suggest is visibly right in the evidence: Gym → dumbbell, pull request → code, dentist → pill, pick up → bag, flights → plane, lunch → plate.
- **A2-G-9 Originality overall holds:** pill-with-chip blocks, no vertical spine, no circular progress, tone-sweep running state, dusty-coral accent, own tab set. The only drift risk is the brand mark (A2-P1-12).
- **A2-G-10 Documented a11y overrides are sound** (culori-measured, not taste) and keep the ratified look.
